# Бюро находок (Lost and Found)

## Описание
REST API для управления бюро находок. Пользователи могут подавать заявления о пропаже и претензии на найденные вещи. Администраторы управляют предметами и подтверждают передачу.

## Роли
* **ROLE_USER**: Регистрация, просмотр, создание заявлений и претензий.
* **ROLE_ADMIN**: Полный доступ, управление предметами, одобрение/отклонение претензий, оформление актов передачи.

## Бизнес-возможности
1. Одобрение претензии.
2. Отклонение претензии.
3. Отмена заявления (с каскадным отклонением претензий).
4. Оформление акта передачи.
5. Поиск совпадений по категории.

## Безопасность
HTTP Basic Auth + CSRF-защита.
